Motion reference

Press · 100ms

Tile scales to 96% under the finger, then returns. No bounce; input never waits for animation.

Entry · 120ms

Newly filled sequence mark grows from 70% to 100%. Feedback stays inside the sequence band.

Navigation · 180 / 140ms

Forward enters from +16px; return from −10px. Ease out: cubic-bezier(.16,1,.3,1).

Control state · 120ms

Theme selection and pressed surfaces change colour. Switch knob travels 14px.

Connecting · 1400ms loop

Amber circle fades to 40% halfway through. Stop immediately when the state changes.

Syncing · 900ms loop

Blue open ring rotates linearly. Retry uses two opacity dips in a 2400ms cycle.

Reduced motion removes transforms, pulses and rotation. Solid / slashed / open-ring / square shapes still identify status. No shimmer, shadows or decorative animation needs porting.

Firmware handoff: use non-blocking LVGL animations; cancel old animations on state changes and screen destruction. Repaint only changed widgets. These timings are design targets, not measured CYD performance. Browser pixels preserve resolution, not physical inches; verify readability and touch accuracy on the actual panel.

Design rationale: quiet warm surfaces support the colour-code task; large flat controls suit touch; the gear saves header space; full-page pickers prevent clipping. Arial is a browser stand-in: choose the firmware font by measured glyph widths. Energy 1 / rhythm 1 / motion 2. Firmware and settings persistence are unchanged.
